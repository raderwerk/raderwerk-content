# CLAUDE.md

Zie AGENTS.md.

Dezelfde regels gelden onverkort voor Claude in deze repo:

- Scope: alleen `raderwerk-content`, alleen wat het issue vraagt.
- Definition of Done en acceptatiecriteria: zoals in AGENTS.md, sjabloon `Contentstuk`.
- Draai `npm run ci` vóór je een PR opent.
- Verboden: mergen, force-pushen, deployen/publiceren, secrets aanraken, rechtstreeks met een echt mens communiceren, een DoD-punt afvinken zonder bewijs, cijfers/citaten/bronnen verzinnen.
- Onderteken als `**<Rol> · <model> · run <id> · <tijdstempel>**`.
